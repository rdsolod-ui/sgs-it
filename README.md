# SGS IT / parkops

Сайт SGS IT (ООО «ВоркСинк Системс»): полноэкранный диалог с модульным 3D-маскотом, презентация parkops и мини-CRM.

**Публичная демонстрация:** https://marketing.parkskazka.ru/sgs-it/

На публичном стенде чат работает в браузере по сценариям. Сообщения не отправляются на API, заявки не принимаются. Рабочий сервер с PostgreSQL и CRM развёртывается отдельно.

## Стек

React / TypeScript / Vite, Three.js / React Three Fiber, Fastify, PostgreSQL. 3D-модель создана в Blender и поставляется в GLB; исходная сцена находится в `assets/blender/`.

## Локальный запуск

Требуются Node.js 24, npm, PostgreSQL 18.

```sh
npm ci
cp .env.example .env
# Укажите DATABASE_URL и APP_ORIGIN в .env.
npm run db:migrate
# Пароль администратора передаётся через stdin и хранится как Argon2-хэш.
npm run admin:create
npm run dev
```

`npm run admin:create` читает stdin до EOF; используйте защищённый менеджер секретов или локальный интерактивный ввод, не записывайте пароль в командную строку.

```sh
npm test
npm run build
npm run test:integration
npm run test:browser
npm run build:preview
```

- `dist/` + `dist-server/` — рабочее приложение.
- `dist-preview/` — изолированная статическая демонстрация для `/sgs-it/`.
- `npm run test:integration` — требует тестовую PostgreSQL и запущенный API.
- `npm run test:browser` — использует отдельный Chrome CDP или headless-браузер при `BROWSER_HEADLESS=1`.

## Разработка и релизы

Изменения: ветка `codex/...` → проверки → `main` → релиз из того же commit SHA → VPS. GitHub Actions проверяет сборку, тесты и формирует артефакты. Доступ к VPS остаётся вне публичного репозитория.

## Ограничения MVP

Внешний AI по умолчанию отключён. Его включение требует подходящего аккаунта/региона и проверки схемы обработки данных. Документы согласий в коде — шаблоны, которые оператор заполняет и проверяет перед приёмом реальных заявок. Telegram требует отдельного бота. Секреты, базы, диалоги пользователей и внутренние исследования не публикуются.

Код опубликован для прозрачной совместной разработки; лицензия на сторонние шрифты находится в `public/fonts/`. Размещение исходников в открытом доступе само по себе не предоставляет отдельную лицензию на продукт и фирменные материалы.
